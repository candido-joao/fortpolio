Sistema corporativo para gestão de projetos, atividades e alocação de recursos humanos, com módulos integrados de controle de horas, planejamento ágil e inventário. Fornece dashboards analíticos, visualizações em Kanban e Gantt, além de relatórios exportáveis. Suporta comunicação assíncrona via WebSocket e processamento de tarefas em background.

Destaques técnicos

  • Migração progressiva do frontend para arquitetura moderna sem big-bang rewrite: camada refactor/ com Tailwind v4, TanStack Query v5, Radix UI e padrão view-model convive com código legado em MUI/Axios/Redux, permitindo evolução incremental sem paralisar entregas
  • Backend com Dependency Injection via dependency-injector: serviços resolvidos por container, desacoplando camada de negócio dos ViewSets do DRF e facilitando testes unitários com mocks por substituição de binding
  • Stack assíncrona dupla: Celery + Redis para tarefas de longa duração (geração de PDFs com WeasyPrint, exportações com Pandas/OpenPyXL) e Django Channels para comunicação em tempo real, ambos containerizados e monitorados via Flower
  • Pipeline CI/CD com builds multi-stage Docker (Node 22 → Caddy para frontend; Python 3.12 → slim runtime para backend), reduzindo tamanho de imagem e separando artefatos de build de artefatos de runtime
  • Integração de IA generativa (Gemini) como módulo plugável, isolado do core de negócio, com abstração de serviço que permite troca de provider sem impacto nos chamadores

Plataforma SaaS multi-tenant com autenticação completa, autorização baseada em grupos e permissões, gestão de projetos e equipes, e integração de cobrança por assinatura. O backend expõe uma API REST assíncrona consumida por um frontend React com roteamento baseado em arquivos, gerenciamento de estado de servidor e suporte a múltiplos idiomas. Suporta comunicação em tempo real via WebSocket e processamento de tarefas assíncronas via fila de mensagens.

Destaques técnicos

  • Adoção de Ports & Adapters por módulo: cada adaptador concreto (Redis, SQL, Stripe, aiosmtplib) implementa uma interface abstrata (Port), permitindo substituição e teste com fakes sem alterar lógica de negócio
  • Pipeline assíncrono de e-mail via RabbitMQ + FastStream: requests HTTP não bloqueiam no envio de e-mail — a tarefa é publicada na fila e consumida por um worker separado (start-stream), desacoplando latência de SMTP do ciclo request/response
  • Token refresh transparente no frontend: o cliente Ky intercepta respostas 401, executa refresh de token e re-envia a request original automaticamente, com deduplicação para evitar múltiplas chamadas simultâneas de refresh
  • Tipagem end-to-end: o schema OpenAPI gerado pelo FastAPI é convertido em tipos TypeScript via openapi-typescript, eliminando drift entre contratos de API e consumo no frontend
  • Observabilidade completa em desenvolvimento: stack local com OpenTelemetry (traces), Prometheus (métricas), Loki (logs) e Tempo, todos coletados pelo Grafana Alloy e visualizados no Grafana
  • Multi-tenancy com isolamento por políticas de permissão: acesso a recursos é validado por Policy classes no nível de serviço, combinando tenant_id + grupo/permissão do usuário antes de qualquer operação
  • Build multi-stage com imagem mínima de produção: Dockerfile em 4 estágios (base → builder → migrations → runtime) gera imagem final sem ferramentas de build, rodando como usuário não-root (uid 1001)

Plataforma web para acompanhamento em tempo real do ciclo de vida de registros logísticos, com visualização em modo Kanban e lista. Destaques técnicos

  • Pipeline CI/CD completo com 12 workflows GitHub Actions: lint, typecheck, format em PRs; deploy separado para dev e prod; deploy autônomo de Edge Functions; build Docker com migrations atômicas em transação única para rollback seguro
  • Permissões temporárias via store dedicado: modelo de concessão de edição granular por registro, sem alterar RLS do banco, gerenciado em estado efêmero no cliente
  • Ambiente validado em runtime com Zod: variáveis de ambiente parseadas e tipadas no boot, lançando erro explícito em vez de falhar silenciosamente em produção

O sistema centraliza fluxos de inspeção, manutenção, aprovação de documentos, checklists e registros operacionais de campo. Destaques técnicos

  • RoutingChatModel customizado sobre Spring AI para rotear chamadas entre múltiplos provedores de LLM (Anthropic, OpenAI, Gemini) com rastreamento de custo de tokens via IaCostService

  • Geração de relatórios server-side combinando JasperReports (PDF) e Apache POI (XLSX) a partir das mesmas fontes de dados, servidos via endpoints REST autenticados por JWT
